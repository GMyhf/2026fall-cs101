## T1. 成绩单核对

**考点**：字典计数、多关键字排序、格式化输出（W2、W4）　　**难度**：★☆☆☆☆

### 题面

有 n 条成绩记录，每条包含**学号**（7 位数字字符串）、**科目名**（小写字母，长度 ≤ 10）和**分数**（0–100 的整数）。

请按**总分从高到低**输出每个学号的总分与平均分（保留两位小数）；**总分相同时按学号字典序从小到大**。

**输入**
第一行一个整数 n（1 ≤ n ≤ 2×10⁵）。
接下来 n 行，每行 `学号 科目 分数`，以空格分隔。

**输出**
每个学号一行：`学号 总分 平均分`（平均分保留两位小数）。

**样例输入**
```
5
2200011 math 90
2200011 physics 80
2200012 math 95
2200012 physics 75
2200013 math 85
```

**样例输出**
```
2200011 170 85.00
2200012 170 85.00
2200013 85 85.00
```

**样例解释**：2200011 与 2200012 总分同为 170，按学号升序排列。

### 参考解答

```python
import sys
from collections import defaultdict


def solve():
    data = sys.stdin.read().split()
    n = int(data[0])
    total = defaultdict(int)
    cnt = defaultdict(int)
    idx = 1
    for _ in range(n):
        sid, _subject, score = data[idx], data[idx + 1], int(data[idx + 2])
        idx += 3
        total[sid] += score
        cnt[sid] += 1
    order = sorted(total, key=lambda s: (-total[s], s))
    out = [f"{s} {total[s]} {total[s] / cnt[s]:.2f}" for s in order]
    sys.stdout.write('\n'.join(out) + '\n')


solve()
```

### 数据构造建议

- **卡 O(n²)**：n = 2×10⁵ 条记录但只有 500 个不同学号 —— 用 `list.count()` 或
  每次线性查找会稳定 TLE。
- **卡排序键**：构造大量总分相同的学号，检验并列时是否按**学号升序**。
- **卡格式**：平均分恰好为整数（如 85）时必须输出 `85.00`，不能是 `85.0` 或 `85`。
- **卡输入规模**：用 `input()` 逐行读 2×10⁵ 行会明显变慢，检验是否用了快速输入。

### 评分标准

| 项 | 分值 |
| ---- | ---- |
| 用字典一遍统计（而非重复扫描） | 6 |
| 多关键字排序 `(-total, sid)` 正确 | 5 |
| 平均分格式 `:.2f` 正确 | 4 |

## T2. 括号嵌套深度

**考点**：栈、边界判断（W7）　　**难度**：★★☆☆☆

### 题面

给定一个字符串 s，其中可能包含 `(` `)` `[` `]` `{` `}` 以及其他任意可见字符。

- 若括号**完全匹配**，输出 `YES` 和**最大嵌套深度**（用空格分隔）；
- 否则输出 `NO` 和**第一个出错位置**（1-indexed）。

"出错位置"定义为：
1. 遇到一个右括号，但栈为空或栈顶与之不配对 → 该右括号的位置；
2. 扫描结束时仍有未闭合的左括号 → 位置为 `len(s) + 1`。

**输入**：一行字符串 s（0 ≤ |s| ≤ 10⁶，不含空格）。

**输出**：一行，格式如上。

**样例输入**
```
a(b[c]{d})e
```

**样例输出**
```
YES 2
```

**更多样例**

| 输入 | 输出 | 说明 |
| ---- | ---- | ---- |
| `(]` | `NO 2` | 第 2 位的 `]` 与栈顶 `(` 不配对 |
| `((()` | `NO 5` | 扫描结束仍有 2 个 `(` 未闭合，输出 `4+1=5` |
| `()[]{}` | `YES 1` | 三对括号并列，最大深度为 1 |
| `(([]))` | `YES 3` | 最深处是 `[]`，嵌套 3 层 |

### 参考解答

```python
import sys


def solve():
    s = sys.stdin.readline().rstrip('\n')
    pairs = {')': '(', ']': '[', '}': '{'}
    stack, depth, best = [], 0, 0
    for i, ch in enumerate(s):
        if ch in '([{':
            stack.append(ch)
            depth += 1
            if depth > best:
                best = depth
        elif ch in pairs:
            if not stack or stack[-1] != pairs[ch]:
                print("NO", i + 1)
                return
            stack.pop()
            depth -= 1
    if stack:
        print("NO", len(s) + 1)
    else:
        print("YES", best)


solve()
```

### 数据构造建议

- **空串**：输出应为 `YES 0`。
- **只有非括号字符**：`abcdef` → `YES 0`。
- **深嵌套**：10⁵ 层 `((((...))))` —— 检验是否用了递归（会爆栈）而非栈。
- **先深后错**：`((([))` —— 检验是否在报错前误输出了深度。
- **末尾未闭合**：`(((` → `NO 4`，检验 `len(s)+1` 这个边界。

### 评分标准

| 项 | 分值 |
| ---- | ---- |
| 栈匹配逻辑正确（三类错误全覆盖） | 8 |
| 最大深度统计正确 | 4 |
| 未闭合时输出 `len(s)+1` | 3 |

## T3. 会议室数量

**考点**：区间分组、差分 / 排序（W10）　　**难度**：★★★☆☆

### 题面

有 n 场会议，第 i 场的时间是**左闭右开**区间 [aᵢ, bᵢ)（即 bᵢ 时刻可以立刻安排下一场）。
求最少需要多少间会议室，使所有会议都能进行。

**输入**
第一行整数 n（1 ≤ n ≤ 2×10⁵）。
接下来 n 行，每行两个整数 aᵢ bᵢ（0 ≤ aᵢ < bᵢ ≤ 10⁹）。

**输出**：一个整数。

**样例输入**
```
3
0 30
5 10
15 20
```

**样例输出**
```
2
```

**样例解释**：[5,10) 与 [15,20) 可共用一间（前者结束后者才开始），[0,30) 独占一间。

### 参考解答

**思路**：答案 = **同一时刻最多有多少场会议在进行**。
把每场会议拆成"+1（开始）"和"−1（结束）"两个事件，按时间排序后扫描求峰值。

**关键细节**：左闭右开时，同一时刻的 `−1` 必须排在 `+1` **前面**（先释放再占用）。
Python 中 `(t, -1) < (t, 1)` 自动满足这一点。

```python
import sys


def solve():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    events = []
    idx = 1
    for _ in range(n):
        a, b = int(data[idx]), int(data[idx + 1])
        idx += 2
        events.append((a, 1))
        events.append((b, -1))
    events.sort()                      # (t, -1) 排在 (t, 1) 前面
    cur = best = 0
    for _, delta in events:
        cur += delta
        if cur > best:
            best = cur
    print(best)


solve()
```

**堆写法**（等价，便于理解"分组"的含义）：

```python
import heapq


def min_rooms(intervals):
    intervals = sorted(intervals, key=lambda x: x[0])
    heap = []                           # 各会议室当前的结束时间
    for a, b in intervals:
        if heap and heap[0] <= a:       # 最早结束的那间已空出（左闭右开取 <=）
            heapq.heapreplace(heap, b)
        else:
            heapq.heappush(heap, b)
    return len(heap)


print(min_rooms([(0, 30), (5, 10), (15, 20)]))     # 2
print(min_rooms([(1, 4), (2, 5), (6, 8), (3, 7)])) # 3
```

### 数据构造建议

- **端点相接**：大量 `[0,1) [1,2) [2,3) ...` —— 若把 `−1` 排在 `+1` 之后，会错答成 2。
- **全嵌套**：`[0,n) [1,n-1) [2,n-2) ...` —— 答案应等于 n。
- **坐标范围 10⁹**：检验是否试图开长度为坐标范围的数组（会 MLE）。
- **n = 2×10⁵**：检验是否用了 O(n²) 的两两比较。

### 评分标准

| 项 | 分值 |
| ---- | ---- |
| 想到"求同时进行的峰值"这一转化 | 7 |
| 事件排序 / 堆写法实现正确 | 5 |
| 左闭右开的边界处理正确 | 3 |

## T4. 穿墙迷宫

**考点**：带状态的 BFS（W12）　　**难度**：★★★☆☆

### 题面

n×m 的网格，`.` 表示空地、`#` 表示墙、`S` 是起点、`T` 是终点（`S` 与 `T` 都是空地）。
每一步可以走到上下左右相邻的格子；**最多可以穿过 k 面墙**（穿墙同样计 1 步）。
求从 `S` 到 `T` 的最少步数。

**输入**
第一行三个整数 n m k（1 ≤ n, m ≤ 500，0 ≤ k ≤ 10）。
接下来 n 行，每行 m 个字符。

**输出**：最少步数；若无法到达（即使用满 k 次穿墙也不行）输出 `-1`。

**样例输入**
```
3 5 2
S#.#T
.#.#.
.....
```

**样例输出**
```
4
```

**样例解释**：穿过 (1,2) 与 (1,4) 两面墙，走 `S → # → . → # → T`，共 4 步。
若 k = 0 或 k = 1，则必须绕行，答案均为 8。

### 参考解答

**关键**：状态是 **`(x, y, 已穿墙次数)`** —— 把网格复制成 k+1 层。

```python
import sys
from collections import deque


def solve():
    data = sys.stdin.read().split()
    n, m, k = int(data[0]), int(data[1]), int(data[2])
    grid = data[3:3 + n]
    sx = sy = tx = ty = -1
    for i in range(n):
        row = grid[i]
        for j in range(m):
            if row[j] == 'S':
                sx, sy = i, j
            elif row[j] == 'T':
                tx, ty = i, j
    DIRS = ((-1, 0), (1, 0), (0, -1), (0, 1))
    # dist[used][x][y]
    dist = [[[-1] * m for _ in range(n)] for _ in range(k + 1)]
    dist[0][sx][sy] = 0
    q = deque([(sx, sy, 0)])
    while q:
        x, y, u = q.popleft()
        if (x, y) == (tx, ty):
            print(dist[u][x][y])
            return
        for dx, dy in DIRS:
            nx, ny = x + dx, y + dy
            if not (0 <= nx < n and 0 <= ny < m):
                continue
            nu = u + (1 if grid[nx][ny] == '#' else 0)
            if nu > k or dist[nu][nx][ny] >= 0:
                continue
            dist[nu][nx][ny] = dist[u][x][y] + 1
            q.append((nx, ny, nu))
    print(-1)


solve()
```

**为什么普通 BFS 是对的（不需要 Dijkstra）**：每一步的代价都是 1（穿墙也是 1 步），
边权相同，所以 BFS 第一次到达 `T` 就是最短。**若穿墙代价不是 1，就必须换成 Dijkstra。**

### 数据构造建议

- **k = 0 且被墙完全隔开** → `-1`；
- **k 足够大** → 答案退化为曼哈顿距离；
- **500×500 且 k = 10** → 状态数 2.75×10⁶，检验是否用 `deque`（用 `list.pop(0)` 必 TLE）；
- **只用 `visited[x][y]` 一层**的错解：在样例上就会答成 8 而非 4 —— 这是最典型的错法，
  样例必须能卡住它；
- **S 与 T 相邻且中间是墙**：`S#T`，k=0 → −1，k=1 → 2。

### 评分标准

| 项 | 分值 |
| ---- | ---- |
| 状态加"已穿墙次数"这一维 | 7 |
| BFS 实现正确（deque + 入队标记） | 5 |
| 边界（不可达、k=0、S/T 相邻）正确 | 3 |

## T5. 作业时间分配

**考点**：0-1 背包 + 次要目标（W11）　　**难度**：★★★★☆

### 题面

期末周还剩 T 分钟。有 n 份作业，第 i 份需要 tᵢ 分钟，完成可得 sᵢ 分。
每份作业**要么完整完成、要么不做**。

求在总时间不超过 T 的前提下能拿到的**最高总分**；
若有多种方案能拿到最高分，再求其中**总耗时最少**的那个耗时。

**输入**
第一行两个整数 n T（1 ≤ n ≤ 100，1 ≤ T ≤ 10⁴）。
接下来 n 行，每行两个整数 tᵢ sᵢ（1 ≤ tᵢ ≤ T，1 ≤ sᵢ ≤ 10⁴）。

**输出**：一行两个整数——最高总分、达到该总分的最小耗时。

**样例输入**
```
4 10
3 10
4 14
5 16
2 5
```

**样例输出**
```
31 10
```

**样例解释**：选第 1、2、4 份（3+4+2 = 9 分钟，10+14+5 = 29 分）不是最优；
选第 1、3、4 份（3+5+2 = 10 分钟，10+16+5 = 31 分）为最优，耗时 10 分钟。

### 参考解答

**双目标 DP**：主目标最大化得分，次目标最小化耗时。
维护两个数组：`dp[c]` = 容量 c 下的最高分，`tm[c]` = 达到该分数的最小耗时。

```python
import sys


def solve():
    data = sys.stdin.read().split()
    n, T = int(data[0]), int(data[1])
    dp = [0] * (T + 1)          # 最高得分
    tm = [0] * (T + 1)          # 达到 dp[c] 的最小耗时
    idx = 2
    for _ in range(n):
        t, s = int(data[idx]), int(data[idx + 1])
        idx += 2
        for c in range(T, t - 1, -1):        # 0-1 背包：倒序
            cand = dp[c - t] + s
            if cand > dp[c] or (cand == dp[c] and tm[c - t] + t < tm[c]):
                dp[c] = cand
                tm[c] = tm[c - t] + t
    best = max(dp)
    min_time = min(tm[c] for c in range(T + 1) if dp[c] == best)
    print(best, min_time)


solve()
```

> **两个易错点**：
> 1. **必须倒序**（0-1 背包），正序会让同一份作业被做多次；
> 2. 两个分支缺一不可：`cand > dp[c]`（**分更高就必须覆盖**）
>    与 `cand == dp[c] and tm[c-t] + t < tm[c]`（**分相同时才比耗时**）。
>    只写后一支（`if cand >= dp[c] and tm[c-t] + t < tm[c]`）会漏掉"分更高"的情况，
>    样例直接输出 `0 0`。
>    （注意：把第二支里的 `==` 单独换成 `>=` 反而**与原式等价** ——
>    因为 `cand > dp[c]` 那一支已经在 `or` 的左边了。错的是**少一支**，不是这个符号。）

### 数据构造建议

- **多方案同分**：构造两组作业得分相同但耗时不同（如 `(3,10)` `(5,10)`），检验次要目标；
- **T = 10⁴、n = 100**：10⁶ 次转移，检验是否写成了 O(n·T·n) 的三重循环；
- **所有 tᵢ > T**：答案应为 `0 0`；
- **单份作业恰好用满 T**：检验倒序边界 `range(T, t-1, -1)`；
- **暴力对拍**：n ≤ 15 时用 2ⁿ 枚举子集，验证 (得分, 耗时) 两个目标都对。

### 评分标准

| 项 | 分值 |
| ---- | ---- |
| 0-1 背包主目标正确（含倒序） | 10 |
| 次要目标"同分取最小耗时"正确 | 7 |
| 边界（无解、恰好用满）正确 | 3 |

## T6. 电网巡检

**考点**：最小瓶颈路 = 排序 + 并查集（W6、W9）；亦可二分 + BFS（W12）　　**难度**：★★★★★

### 题面

电网有 n 个变电站（编号 1..n）和 m 条双向线路，第 j 条连接 uⱼ 与 vⱼ，**危险度**为 wⱼ。

巡检队要从 1 号站走到 n 号站。一条路径的"风险"定义为**该路径上所有线路危险度的最大值**。
求所有路径中风险的**最小值**。

**输入**
第一行两个整数 n m（2 ≤ n ≤ 10⁵，1 ≤ m ≤ 2×10⁵）。
接下来 m 行，每行三个整数 uⱼ vⱼ wⱼ（1 ≤ uⱼ, vⱼ ≤ n，uⱼ ≠ vⱼ，1 ≤ wⱼ ≤ 10⁹）。

**输出**：最小风险值；若 1 与 n 不连通，输出 `-1`。

**样例输入**
```
4 4
1 2 5
2 3 3
3 4 7
1 4 6
```

**样例输出**
```
6
```

**样例解释**：路径 1→4 的风险是 6；路径 1→2→3→4 的风险是 max(5,3,7) = 7。取较小者 6。

### 参考解答

**核心洞察**：**按危险度从小到大逐条加入线路**，第一次让 1 与 n 连通的那条线路的危险度，
就是答案。因为再小的危险度上限都无法连通 1 与 n。

```python
import sys


def solve():
    data = sys.stdin.buffer.read().split()
    n, m = int(data[0]), int(data[1])
    edges = []
    idx = 2
    for _ in range(m):
        u, v, w = int(data[idx]), int(data[idx + 1]), int(data[idx + 2])
        idx += 3
        edges.append((w, u, v))
    edges.sort()                              # 按危险度升序

    parent = list(range(n + 1))
    size = [1] * (n + 1)

    def find(x):
        root = x
        while parent[root] != root:
            root = parent[root]
        while parent[x] != root:              # 路径压缩（迭代，防爆栈）
            parent[x], x = root, parent[x]
        return root

    for w, u, v in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            if size[ru] < size[rv]:
                ru, rv = rv, ru
            parent[rv] = ru
            size[ru] += size[rv]
        if find(1) == find(n):
            print(w)
            return
    print(-1)


solve()
```

**另一种解法：二分答案 + BFS**（O((n+m) log W)，思路更直观但更慢）：

```python
from collections import defaultdict, deque


def min_risk_binary(n, edges):
    values = sorted({w for w, _, _ in edges})

    def connected(limit):
        adj = defaultdict(list)
        for w, u, v in edges:
            if w <= limit:
                adj[u].append(v)
                adj[v].append(u)
        seen = {1}
        q = deque([1])
        while q:
            x = q.popleft()
            for y in adj[x]:
                if y not in seen:
                    seen.add(y)
                    q.append(y)
        return n in seen

    lo, hi = 0, len(values) - 1
    if not connected(values[hi]):
        return -1
    while lo < hi:
        mid = (lo + hi) // 2
        if connected(values[mid]):
            hi = mid
        else:
            lo = mid + 1
    return values[lo]


print(min_risk_binary(4, [(5, 1, 2), (3, 2, 3), (7, 3, 4), (6, 1, 4)]))   # 6
print(min_risk_binary(3, [(1, 1, 2)]))                                    # -1
```

### 数据构造建议

- **不连通**：n = 3、只有边 (1,2) → `-1`；
- **重边**：同一对点多条不同危险度的边，检验是否取到最小的那条；
- **链状图**：1–2–3–…–n，检验并查集是否退化（未做路径压缩会 TLE）；
- **n = 10⁵、m = 2×10⁵**：检验是否用了快速输入与 `sort`；
- **全部边权相同**：答案就是该权值，检验"第一次连通即返回"的逻辑；
- **交叉验证**：用二分 + BFS 的实现与并查集实现在随机小图上对拍（本题已做 400 组）。

### 评分标准

| 项 | 分值 |
| ---- | ---- |
| 想到"按边权升序加边，首次连通即答案"（或等价的二分判定） | 10 |
| 并查集实现正确（路径压缩 + 按大小合并） | 6 |
| 不连通输出 `-1`、重边处理正确 | 4 |

3. ⚠️ 平时的自检方法：**关掉所有窗口，从空文件重写一遍**。写不出来 = 这道题你没做。

# 8 命题与阅卷检查清单（教师用）

## 8.1 命题前

- [ ] 6 题覆盖第 4 节矩阵中**至少 5 个大类**，且贪心 / DP / 搜索各至少 1 题；
- [ ] 难度梯度符合 ★1 → ★5，T1 是真正的签到题；
- [ ] 每题的数据范围**明确写出**，且与预期复杂度匹配；
- [ ] 每题至少给出 1 组样例，**并对易误解的输出定义给出样例解释**
      （如 T2 的"未闭合位置 = len(s)+1"、T3 的左闭右开）；
- [ ] 题面中没有歧义的边界描述（区间开闭、是否含端点、多解如何取）。

## 8.2 参考解答

- [ ] 每题的参考解答**已实际运行**并通过全部样例；
- [ ] 已测边界：n=1、空输入、全相同、极值、不连通；
- [ ] 已与暴力解**对拍**（本卷 T3 / T4 / T5 / T6 各做了 400 组随机对拍）；
- [ ] 复杂度声明与实际行为一致；
- [ ] 递归解法已确认不会在评测机上爆栈（或已改迭代）。

## 8.3 测试数据

- [ ] 每题都有**卡错解**的数据（第 5 节各题的"数据构造建议"）；
- [ ] 每题都有**卡超时**的数据，且已用错误复杂度的实现验证过它真能卡住；
- [ ] 分档数据设计合理（部分通过给部分分）；
- [ ] 时限按参考解答实测时间的 **3–5 倍**设定，并考虑 Python 与 C++ 的差异。

## 8.4 阅卷

- [ ] 评分标准逐项可核对（见各题"评分标准"表）；
- [ ] 抽查高分卷，要求学生**口头解释自己的代码**；
- [ ] 记录各题实际 AC 率，与第 4 节的预期对照，用于下一年校准。

# 9 小结

1. 16 周的知识体系分四条线：**计算机基础、语言与工具、算法与数据结构、AI 素养**；
   算法主线是 **枚举 → 贪心 / DP → 搜索**，横向工具是前缀和、二分、单调结构、并查集。
2. 机考 **6 题 / 112 分钟**，**禁用一切 AI 工具**，**讲不清自己的代码按学术不端处理**。
3. 样卷的六道题分别对应：**字典排序、栈、区间分组、带状态 BFS、双目标背包、最小瓶颈路**，
   难度从 ★1 递增到 ★5。
4. 备考只做两件事：**默写 12 个模板** + **手写一页 cheat sheet**。抄不下的内容说明还没消化。
5. 考场六条：看范围、早提交、造数据、查复杂度、按时换题、留时间查格式。
