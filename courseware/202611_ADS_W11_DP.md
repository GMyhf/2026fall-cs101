# 1 背包问题：DP 的主干

## 1.1 三种背包一览

| 类型 | 每种物品的数量 | 体积维遍历方向 |
| ---- | ---- | ---- |
| **0-1 背包** | 每种最多 1 个 | **倒序** |
| **完全背包** | 每种无限个 | **正序** |
| **多重背包** | 每种有上限 kᵢ | 二进制拆分后当 0-1 背包 |

> **这张表是背包问题的全部。**倒序 / 正序一个字之差，就是两种完全不同的问题。

## 1.2 0-1 背包

**23421: 小偷背包**（《算法图解》例题），<http://cs101.openjudge.cn/practice/23421/>

> n 个物品，第 i 个体积 wᵢ、价值 vᵢ，背包容量 C，每个物品最多拿一次，求最大总价值。

**二维写法**（先理解这个）：

- **状态**：`dp[i][c]` = 只考虑前 i 个物品、容量为 c 时的最大价值；
- **转移**：`dp[i][c] = max(dp[i-1][c], dp[i-1][c-w[i]] + v[i])`（不拿 / 拿）；
- **边界**：`dp[0][*] = 0`。

```python
def knapsack_2d(weights, values, cap):
    n = len(weights)
    dp = [[0] * (cap + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        w, v = weights[i - 1], values[i - 1]
        for c in range(cap + 1):
            dp[i][c] = dp[i - 1][c]                       # 不拿第 i 个
            if c >= w:
                dp[i][c] = max(dp[i][c], dp[i - 1][c - w] + v)   # 拿
    return dp[n][cap]


print(knapsack_2d([1, 4, 3], [1500, 3000, 2000], 4))      # 3500
```

**一维滚动写法**（实战都用这个）：

```python
def knapsack_1d(weights, values, cap):
    dp = [0] * (cap + 1)
    for w, v in zip(weights, values):
        for c in range(cap, w - 1, -1):        # ⚠️ 必须倒序
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[cap]


print(knapsack_1d([1, 4, 3], [1500, 3000, 2000], 4))      # 3500
```

> ### 为什么 0-1 背包必须倒序
>
> 一维数组里，`dp[c-w]` 在**同一轮**中如果已经被本物品更新过，
> 就相当于这个物品被拿了两次。倒序遍历时 `dp[c-w]` 还是**上一轮**（不含本物品）的值，
> 正好对应二维式子里的 `dp[i-1][c-w]`。
>
> **正序 = 完全背包（可重复拿），倒序 = 0-1 背包（只拿一次）。**

**02773: 采药**，<http://cs101.openjudge.cn/practice/02773/> 是标准 0-1 背包模板题。

import sys


def caiyao(T, herbs):

    for t, v in herbs:

## 1.3 完全背包

**每种物品无限个** → 正序遍历，`dp[c-w]` 用的就是本轮已更新过的值（允许重复拿）。

```python
def unbounded_knapsack(weights, values, cap):
    dp = [0] * (cap + 1)
    for w, v in zip(weights, values):
        for c in range(w, cap + 1):            # ⚠️ 正序
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[cap]


print(unbounded_knapsack([1, 4, 3], [1500, 3000, 2000], 4))   # 6000（拿 4 个体积 1 的）
```

**变形：方案数**（把 `max` 换成 `+`）：

```python
def count_ways(coins, amount):
    """用无限枚硬币凑出 amount 的方案数（组合数，不计顺序）。"""
    dp = [0] * (amount + 1)
    dp[0] = 1
    for c in coins:                            # 物品在外层 -> 组合
        for a in range(c, amount + 1):
            dp[a] += dp[a - c]
    return dp[amount]


def count_permutations(coins, amount):
    """凑出 amount 的排列数（计顺序）。"""
    dp = [0] * (amount + 1)
    dp[0] = 1
    for a in range(1, amount + 1):             # 容量在外层 -> 排列
        for c in coins:
            if c <= a:
                dp[a] += dp[a - c]
    return dp[amount]


print(count_ways([1, 2, 5], 5))          # 4  —— {5},{1,2,2},{1,1,1,2},{1×5}
print(count_permutations([1, 2, 5], 5))  # 9  —— 顺序不同算不同方案
```

> **循环顺序决定语义**：**物品在外层 = 组合（不计顺序），容量在外层 = 排列（计顺序）**。
> 这是背包问题里最容易搞混、也最容易被考的一点。

**M01742: Coins**，<http://cs101.openjudge.cn/practice/01742/> 与
**LeetCode 279. 完全平方数**，<https://leetcode.cn/problems/perfect-squares/> 都是这一类。

```python
def num_squares(n):
    """最少用几个完全平方数凑出 n。完全背包 + 求最小个数。"""
    INF = float('inf')
    dp = [0] + [INF] * n
    k = 1
    while k * k <= n:
        sq = k * k
        for a in range(sq, n + 1):
            if dp[a - sq] + 1 < dp[a]:
                dp[a] = dp[a - sq] + 1
        k += 1
    return dp[n]


print(num_squares(12), num_squares(13))    # 3 (4+4+4)  2 (4+9)
```

## 1.4 多重背包与二进制拆分

**每种物品有 kᵢ 个**。朴素做法是把每个拆成 kᵢ 个单品再做 0-1 背包，复杂度 O(C·Σkᵢ)。

**二进制拆分**：把 k 个同样的物品拆成 `1, 2, 4, ..., 2^t, 余数` 这几"捆"，
用它们能凑出 0..k 的任意个数，把 Σk 降到 Σlog k。

```python
def multi_knapsack(items, cap):
    """items: [(体积, 价值, 数量)]。"""
    dp = [0] * (cap + 1)
    for w, v, k in items:
        cnt = 1
        while k > 0:
            take = min(cnt, k)
            ww, vv = w * take, v * take
            for c in range(cap, ww - 1, -1):       # 每一"捆"当 0-1 背包
                dp[c] = max(dp[c], dp[c - ww] + vv)
            k -= take
            cnt <<= 1
    return dp[cap]


# 3 个体积 2 价值 5 的物品，容量 6 -> 全拿，价值 15
print(multi_knapsack([(2, 5, 3)], 6))       # 15
print(multi_knapsack([(2, 5, 2)], 6))       # 10  —— 只有 2 个
```

**验证二进制拆分的正确性**：1, 2, 4, ..., 2^(t-1), k−(2^t−1) 这些数
能唯一表示 0..k 之间的每个整数。

```python
def binary_split(k):
    parts, cnt = [], 1
    while k > 0:
        take = min(cnt, k)
        parts.append(take)
        k -= take
        cnt <<= 1
    return parts


for k in (1, 5, 7, 10, 13):
    parts = binary_split(k)
    reachable = {0}
    for p in parts:
        reachable |= {r + p for r in reachable}
    assert reachable == set(range(k + 1)), k
    print(k, parts)
# 1 [1]
# 5 [1, 2, 2]
# 7 [1, 2, 4]
# 10 [1, 2, 4, 3]
# 13 [1, 2, 4, 6]
```

## 1.5 "恰好装满"型：初始化的区别

| 目标 | 初始化 |
| ---- | ---- |
| 容量**至多** C 的最大价值 | `dp = [0] * (C+1)` |
| **恰好**装满 C 的最大价值 | `dp[0] = 0`，其余 `-inf` |
| **恰好**装满 C 的最小代价 | `dp[0] = 0`，其余 `+inf` |

```python
def exact_fill_max(weights, values, cap):
    NEG = float('-inf')
    dp = [NEG] * (cap + 1)
    dp[0] = 0                                # 只有容量 0 是"可达"的起点
    for w, v in zip(weights, values):
        for c in range(cap, w - 1, -1):
            if dp[c - w] != NEG:
                dp[c] = max(dp[c], dp[c - w] + v)
    return dp[cap] if dp[cap] != NEG else -1


print(exact_fill_max([2, 3], [10, 20], 5))    # 30，2+3 恰好装满
print(exact_fill_max([2, 4], [10, 20], 5))    # -1，凑不出 5
```

> **`-inf` 的作用是标记"不可达"**。忘了这一步，"恰好装满"型会退化成"至多"型，
> 答案偏大且不报错——**这是最难查的一类 DP bug**。

**21458: 健身房 (dp)**，<http://cs101.openjudge.cn/practice/21458/> 就是"恰好"型；
**20089: NBA门票**，<http://cs101.openjudge.cn/practice/20089/> 是"恰好 + 最小个数"型。

## 1.6 背包的其他变形

**04102: 宠物小精灵之收服**，<http://cs101.openjudge.cn/practice/04102/>——**二维费用背包**
（精灵球数量 + 体力值两个维度）：

```python
def pokemon(balls, hp, pets):
    """pets: [(消耗球数, 消耗体力)]；返回 (最多收服数, 剩余最大体力)。"""
    # dp[b][h] = 用不超过 b 个球、消耗不超过 h 点体力，最多收服几只
    dp = [[0] * (hp + 1) for _ in range(balls + 1)]
    for cost_b, cost_h in pets:
        for b in range(balls, cost_b - 1, -1):
            for h in range(hp, cost_h - 1, -1):
                dp[b][h] = max(dp[b][h], dp[b - cost_b][h - cost_h] + 1)
    best = dp[balls][hp]
    left = 0
    for h in range(hp + 1):
        if dp[balls][h] == best:
            left = hp - h                     # 第一个达到 best 的 h 就是最省体力的
            break
    return best, left


print(pokemon(10, 100, [(7, 10), (2, 40), (2, 50), (1, 20), (4, 20)]))
# (3, 30)
```

**04110: 圣诞老人的礼物**，<http://cs101.openjudge.cn/practice/04110/> 是**分数背包**——
可以只拿一部分，因此**贪心**（按单位价值排序）就是最优，**不需要 DP**。

```python
def fractional_knapsack(items, cap):
    """items: [(总价值, 重量)]，可切分。"""
    items = sorted(items, key=lambda it: it[0] / it[1], reverse=True)
    total, rest = 0.0, cap
    for value, weight in items:
        if rest >= weight:
            total += value
            rest -= weight
        else:
            total += value * rest / weight
            break
    return total


print(f"{fractional_knapsack([(4, 4), (10, 5), (7, 2)], 10):.1f}")   # 20.0
# 单位价值 3.5 -> 2.0 -> 1.0：整取 (7,2) 与 (10,5) 后余 3，(4,4) 只取 3/4 得 3.0
```

> **判断题眼**：物品**可分割** → 贪心；**不可分割** → 背包 DP。
> 这一条在考试里区分度很高。

# 2 序列型 DP

## 2.1 最长上升子序列（LIS）

**02533: Longest Ordered Subsequence**，<http://cs101.openjudge.cn/practice/02533/>

**O(n²) 写法**：

- **状态**：`dp[i]` = 以 a[i] 结尾的最长上升子序列长度；
- **转移**：`dp[i] = max(dp[j] + 1)`，其中 j < i 且 a[j] < a[i]；
- **答案**：`max(dp)`。

```python
def lis_n2(a):
    n = len(a)
    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if a[j] < a[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp) if dp else 0


print(lis_n2([1, 7, 3, 5, 9, 4, 8]))       # 4  —— 1,3,5,9 或 1,3,5,8
```

**O(n log n) 写法**：维护一个数组 `tails`，`tails[k]` = 长度为 k+1 的上升子序列的**最小结尾**。

```python
import bisect


def lis_nlogn(a):
    tails = []
    for v in a:
        pos = bisect.bisect_left(tails, v)   # 严格上升用 bisect_left
        if pos == len(tails):
            tails.append(v)
        else:
            tails[pos] = v                    # 用更小的值替换，为后面留空间
    return len(tails)


print(lis_nlogn([1, 7, 3, 5, 9, 4, 8]))    # 4

import random
for _ in range(200):                          # 两种写法对拍
    t = [random.randint(0, 30) for _ in range(random.randint(1, 25))]
    assert lis_n2(t) == lis_nlogn(t)
print("LIS 两种实现一致")
```

> ⚠️ **`tails` 不是任何一个真实的上升子序列**，它只是各长度的最小结尾。
> 它的**长度**是对的，但直接把它当答案序列输出会错。

**严格上升 vs 非降**：严格用 `bisect_left`，非降（允许相等）用 `bisect_right`。

**M02945: 拦截导弹**，<http://cs101.openjudge.cn/practice/02945/>——
求最长**不上升**子序列，把比较反过来即可：

```python
def longest_non_increasing(a):
    """最长不上升子序列长度 = 反转后取最长不降子序列。"""
    tails = []
    for v in reversed(a):
        pos = bisect.bisect_right(tails, v)
        if pos == len(tails):
            tails.append(v)
        else:
            tails[pos] = v
    return len(tails)


print(longest_non_increasing([389, 207, 155, 300, 299, 170, 158, 65]))   # 6
```

**03532: 最大上升子序列和**，<http://cs101.openjudge.cn/practice/03532/>——
把"长度 +1"换成"和 + a[i]"：

```python
def max_rising_sum(a):
    n = len(a)
    dp = a[:]                                  # dp[i] = 以 i 结尾的最大上升子序列和
    for i in range(n):
        for j in range(i):
            if a[j] < a[i]:
                dp[i] = max(dp[i], dp[j] + a[i])
    return max(dp)


print(max_rising_sum([1, 7, 3, 5, 9, 4, 8]))   # 18 = 1+3+5+9
```

## 2.2 最长公共子序列（LCS）

**02806: 公共子序列**，<http://cs101.openjudge.cn/practice/02806/>

- **状态**：`dp[i][j]` = s[:i] 与 t[:j] 的 LCS 长度；
- **转移**：末字符相同 → `dp[i-1][j-1] + 1`；不同 → `max(dp[i-1][j], dp[i][j-1])`；
- **边界**：`dp[0][*] = dp[*][0] = 0`。

```python
def lcs(s, t):
    m, n = len(s), len(t)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s[i - 1] == t[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]


print(lcs("abcfbc", "abfcab"), lcs("programming", "contest"))    # 4 2
```

**编辑距离**（LeetCode 72，<https://leetcode.cn/problems/edit-distance/>）是同一个二维框架：

```python
def edit_distance(s, t):
    m, n = len(s), len(t)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i                          # 删光
    for j in range(n + 1):
        dp[0][j] = j                          # 全插入
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s[i - 1] == t[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j],        # 删
                                   dp[i][j - 1],        # 插
                                   dp[i - 1][j - 1])    # 改
    return dp[m][n]


print(edit_distance("horse", "ros"), edit_distance("intention", "execution"))   # 3 5
```

## 2.3 打家劫舍：不能取相邻

**LeetCode 198. 打家劫舍**，<https://leetcode.cn/problems/house-robber/>

```python
def rob(nums):
    prev, cur = 0, 0            # prev = dp[i-2], cur = dp[i-1]
    for v in nums:
        prev, cur = cur, max(cur, prev + v)
    return cur


print(rob([1, 2, 3, 1]), rob([2, 7, 9, 3, 1]))     # 4 12
```

> 这是"**选或不选，且选了就跳过下一个**"的最小模型。第 12 周会看到它在网格上的版本。

## 2.4 最大子矩阵

**M02766: 最大子矩阵**，<http://cs101.openjudge.cn/practice/02766/>

> 在 n×n 的整数矩阵中，求元素和最大的子矩阵。

**降维**：枚举上下边界（O(n²) 种），把这几行**按列压缩成一维数组**，
再对它跑 Kadane（O(n)）——总复杂度 O(n³)。

```python
def max_submatrix(mat):
    n, m = len(mat), len(mat[0])
    best = mat[0][0]
    for top in range(n):
        col = [0] * m                          # 第 top..bottom 行的列和
        for bottom in range(top, n):
            row = mat[bottom]
            for j in range(m):
                col[j] += row[j]
            # 对 col 跑 Kadane
            cur = col[0]
            best = max(best, cur)
            for j in range(1, m):
                cur = max(col[j], cur + col[j])
                best = max(best, cur)
    return best


mat = [[0, -2, -7, 0],
       [9, 2, -6, 2],
       [-4, 1, -4, 1],
       [-1, 8, 0, -2]]
print(max_submatrix(mat))                      # 15
```

> **"降维打击"是 DP 的常用招式**：二维问题固定一维，转成已会做的一维问题。
> 第 16 周复习时这是重点模板之一。

# 3 DP 的调试

## 3.1 三个检查点

1. **状态定义能用一句话说清吗？**说不清就一定写不对转移。
2. **边界对不对？**手算 n = 0、1、2 三个最小情况，和代码结果比。
3. **遍历顺序对不对？**转移用到的状态，在用之前算好了吗？

## 3.2 打印 DP 表

n 小的时候把整张表打出来，逐格核对：

```python
def lcs_debug(s, t):
    m, n = len(s), len(t)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            dp[i][j] = (dp[i - 1][j - 1] + 1 if s[i - 1] == t[j - 1]
                        else max(dp[i - 1][j], dp[i][j - 1]))
    print("    " + "  ".join(' ') + "  " + "  ".join(t))
    for i, row in enumerate(dp):
        label = ' ' if i == 0 else s[i - 1]
        print(label, " ".join(f"{v:2d}" for v in row))
    return dp[m][n]


lcs_debug("abc", "ac")
#        a  c
#    0  0  0
# a  0  1  1
# b  0  1  1
# c  0  1  2
```

## 3.3 与暴力对拍

DP 写完后，用暴力枚举验证小规模数据——这是**最可靠**的验证方式：

```python
import itertools
import random


def knapsack_brute(weights, values, cap):
    n = len(weights)
    best = 0
    for mask in range(1 << n):
        w = sum(weights[i] for i in range(n) if mask >> i & 1)
        if w <= cap:
            best = max(best, sum(values[i] for i in range(n) if mask >> i & 1))
    return best


for _ in range(300):
    n = random.randint(1, 10)
    ws = [random.randint(1, 10) for _ in range(n)]
    vs = [random.randint(1, 50) for _ in range(n)]
    cap = random.randint(1, 30)
    assert knapsack_1d(ws, vs, cap) == knapsack_brute(ws, vs, cap)
print("0-1 背包与暴力枚举一致（300 组随机数据）")
```

**思考题**：

1. 0-1 背包的一维写法里，把倒序改成正序，`[(2,3)]`、容量 4 的答案会变成什么？为什么？

# 5 小结

1. 背包三兄弟的区别只在**遍历方向**：**0-1 倒序、完全正序、多重先二进制拆分再当 0-1**。
2. **循环顺序决定语义**：物品在外层 = 组合，容量在外层 = 排列。
3. "**恰好装满**"要把非零位置初始化成 ±inf；忘了它会静默地给出偏大的答案。
4. **物品可分割就贪心，不可分割才 DP**——圣诞老人的礼物是分数背包，不要写成 0-1。
5. LIS 有 O(n²) 与 O(n log n) 两版；`tails` 长度对但序列本身不对。
   LCS / 编辑距离共用同一个二维框架。
6. 二维问题先**降维**：枚举一维 + 对另一维跑一维算法（最大子矩阵 = 枚举行区间 + Kadane）。
7. DP 写完**一定要和暴力对拍**——这是唯一可靠的验证手段。
