# 1 课程概述

## 1.1 这门课教什么

《计算概论（B）》课程编号 04831410，学分 3，**48 学时理论课（每周 3 学时）+ 32 学时上机实习课（每周 2 学时）**。

课程以**编程问题求解**为主线，培养两种思维：

| 思维 | 含义 | 本课的落点 |
| ---- | ---- | ---- |
| 数学思维 | 把现实问题抽象成可计算的模型 | 递推关系、状态定义、复杂度估算 |
| 计算机思维 | 在有限资源下设计可执行的步骤 | 数据结构选型、边界处理、调试 |

完成课程后，你应当能够：

1. 用 Python 完成基本的输入输出、控制结构、函数与常用数据结构操作，并能阅读基础 C++ 程序；
2. 运用复杂度分析、矩阵、排序、贪心、递归、回溯、动态规划和图搜索等方法分析并解决问题；
3. 理解图灵机、进程虚拟地址空间和 ASCII 编码等计算机基本原理；
4. 在 OpenJudge 等在线评测平台独立调试程序、构造测试数据并改进解法。

> 课堂以 **Python** 为主要讲解语言，也支持使用 **C++** 完成练习。

## 1.2 十六周的节奏

| 阶段 | 周次 | 关键词 |
| ---- | ---- | ---- |

一句话版本：**9 月打基础，10 月上强度，11 月攻核心，12 月融会贯通。**

## 1.3 时间投入是硬约束

- **每周课外不少于 8 小时**；零基础同学应按上限安排。
- 一学期预计完成 **150–200 道以上**编程题。
- 学期中不因假期停止练习节奏——中断一周，回来的成本远高于连续做题。

> ⚠️ 这门课的失败模式几乎只有一种：**前四周语法没过关，后面每一周都在还债。**

## 1.4 成绩与考核

课程采用**过程性学习 + 期末考核**：平时作业、阶段性月考（10 月 / 11 月 / 12 月初）、
期末上机考试、笔试。**具体权重与优秀等级条件以当学期正式教学通知为准**，本讲义不预设未公布的比例。

需要现在就知道的两件事：

- **期末上机考试在第 16 周**，机考成绩对总评影响最大（详见第 16 周讲义）。
- 月考的作用是**提前暴露问题**，不是筛人。第一次月考考砸的同学，只要在 11 月前补上语法与调试能力，仍然可以拿到很好的总评。

# 4 AI 基础：把 AI 当工具，不当替身

## 4.1 几个必须分清的词

| 概念 | 一句话解释 |
| ---- | ---- |
| 人工智能 AI | 让机器完成通常需要人类智能的任务，是最大的那个圈 |
| 机器学习 ML | 从数据中学出规律，而不是把规则写死在代码里 |
| 深度学习 DL | 用多层神经网络做机器学习（第 15 周展开） |
| 大语言模型 LLM | 在海量文本上训练的、以"预测下一个词"为目标的深度模型 |

四者的关系是**层层包含**：AI ⊃ ML ⊃ DL ⊃ LLM。

```
   ┌───────────────── 人工智能 AI ─────────────────┐
   │  ┌────────────── 机器学习 ML ──────────────┐  │
   │  │  ┌─────────── 深度学习 DL ───────────┐  │  │
   │  │  │        大语言模型 LLM             │  │  │
   │  │  └───────────────────────────────────┘  │  │
   │  └─────────────────────────────────────────┘  │
   └───────────────────────────────────────────────┘
```

## 4.2 大模型为什么会"一本正经地胡说"

LLM 的训练目标是"**下一个词是什么最合理**"，不是"这句话是不是真的"。所以：

- 它**擅长**：解释概念、翻译报错信息、给出代码骨架、指出常见坑。
- 它**不可靠**：具体的题号与链接、精确的数值结论、课程事务、没见过的新题的正确解法。

> 本课程有一条实测经验：**AI 生成的 OJ 题号经常是错的**。凡是题号，一律自己打开链接确认。

## 4.3 AI 的正确用法：三个可以，三个不可以

**可以**：

1. 让 AI **解释**你不懂的报错、语法、算法思想；
2. 让 AI **审查**你已经写完的代码，问"这段代码在什么输入下会出错"；
3. 让 AI **出题**：让它构造边界数据，然后你自己去验证。

**不可以**：

1. ❌ 直接让 AI 写作业代码然后提交——你没学到，机考时没有 AI；
2. ❌ 相信 AI 给出的题号、成绩规则、考试安排；
3. ❌ **在考试中使用任何 AI 工具**，包括本地模型和 IDE 的智能补全插件。

> ⚠️ **红线**：期末上机考试**禁止任何 AI 工具**；**无法解释自己提交的代码，按学术不端处理**。
> 这条规则从第 1 周就生效于你的学习方式：**每一行你提交的代码，都要能讲清楚为什么这么写。**

## 4.4 一个自检问题

每次借助 AI 完成一道题后，关掉窗口，**从空文件重写一遍**。写不出来，说明这道题没做完。

## 5.2 输入的三种基本形态

OJ 的输入永远来自标准输入。三种最常见的形态：

```python
# 形态一：一行一个整数
n = int(input())

# 形态二：一行多个整数，空格分隔
a, b = map(int, input().split())

# 形态三：一行一个整数列表
nums = list(map(int, input().split()))
```

`input()` 读回来的**永远是字符串**，末尾不含换行符。忘了 `int()` 是初学者第一大坑：

```python
a = input()          # 输入 3
b = input()          # 输入 4
print(a + b)         # 输出 34 —— 字符串拼接，不是 7
print(int(a) + int(b))   # 输出 7
```

## 5.3 输出的格式控制

```python
print("Hello", "World")            # Hello World（默认空格分隔）
print("Hello", "World", sep="-")   # Hello-World
print("a", end="")                 # 不换行
print(f"{3.14159:.2f}")            # 3.14
print(*[1, 2, 3])                  # 1 2 3   —— 解包，OJ 输出数组的标准写法
```

## 5.4 第一道 OJ 题：E02750: 鸡兔同笼

**E02750: 鸡兔同笼**，<http://cs101.openjudge.cn/practice/02750/>

> 笼子里有鸡（2 只脚）和兔（4 只脚），已知脚的总数 a，求最少和最多可能有多少只动物。

**分析**：

- 要动物**最少** → 尽量用兔（4 只脚一只动物）；
- 要动物**最多** → 全用鸡（2 只脚一只动物）；
- a 为奇数、或 a = 0 时无解，输出 `0 0`。

```python
a = int(input())
if a <= 0 or a % 2 == 1:
    print(0, 0)
else:
    least = a // 4 if a % 4 == 0 else a // 4 + 1
    most = a // 2
    print(least, most)
```

**为什么最少是 `a//4` 向上取整**：先全放兔子，剩下的 2 只脚只能再加一只鸡。
`a % 4 == 2` 时，`a//4` 只兔 + 1 只鸡 = `a//4 + 1` 只。

## 5.5 第二道：E02733: 判断闰年

**E02733: 判断闰年**，<http://cs101.openjudge.cn/practice/02733/>

闰年规则：能被 4 整除且不能被 100 整除，**或**能被 400 整除。（本题另有"不能被 3200 整除"的附加条件，务必看清题面。）

```python
y = int(input())
leap = (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0 and y % 3200 != 0)
print("Y" if leap else "N")
```

> **本周最重要的一课**：先把**题面读完**，再动手。上面这道题绝大多数 WA 都来自漏看 3200。
