## P4｜三大操作系统

先把三大操作系统横向对一遍。

内核方面，Windows 是 NT 内核，macOS 是 Darwin，属于类 Unix，Linux 就是 Linux 内核。

默认的 Shell，Windows 是 PowerShell 或者 cmd，macOS 是 zsh，Linux 上常见的是 bash 和 zsh。

包管理，Windows 用 winget 或者 choco，macOS 用 Homebrew，Linux 用 apt 或者 yum。

路径分隔符，Windows 用反斜杠，另外两家用正斜杠。

最后一行是最容易咬人的：换行符。Windows 是回车加换行两个字符，macOS 和 Linux 只有一个换行符。这个差异会在你读取跨平台的输入文件时表现成一个看不见的多余字符。所以请养成一个习惯：读进来的每一行都先 strip 一下。

在本课里，Windows 和 macOS 是你的主力开发机，Linux 是评测机和云主机。

## P5｜虚拟机的层次

这张图从下往上看，一共四层。

最下面是物理硬件。硬件之上是宿主机的操作系统，也就是你笔记本上那个 Windows 或者 macOS。再往上一层是虚拟机监视器，常见的有 VirtualBox、VMware、KVM。最上面才是一个个虚拟机，每个虚拟机里跑着自己的操作系统，可以是 Linux，也可以是 Windows。

虚拟机给你三样东西：隔离，一台虚拟机搞坏了不影响宿主机；一致，同一个镜像在谁的机器上都长一样；可迁移，整台机器可以打包搬走。

## P6｜虚拟机与容器的区别

容器经常和虚拟机被放在一起说，但它们不是一回事。

虚拟机模拟的是一整台计算机，它有自己的内核，所以启动慢、开销大，好处是可以跑和宿主机完全不同的系统。

容器，比如 Docker，共享宿主机的内核，只隔离文件系统和进程，所以启动快、开销小；代价是它不能跑一个需要不同内核的系统。

一句话记法：虚拟机隔离的是硬件，容器隔离的是环境。

## P7｜云主机：连接与首次配置

这一页是你第一次连上一台云主机时要敲的命令。

连接用 ssh，后面跟用户名、at 符号、再跟 IP 地址，这是口令登录。更推荐的是密钥登录，用减 i 参数指定私钥文件。

拿到一台新机器，先做三件事。

第一件，更新系统，先 apt update 再 apt upgrade。

第二件，生成密钥对并上传公钥。在你本机执行 ssh keygen，指定 ed25519 类型，再用 ssh copy id 把公钥送到云主机上。此后就不用每次输入口令了。

第三件，学会传文件。scp 后面先写来源再写目标，从本机传到云主机，或者反过来从云主机取回结果，方向由这两个参数的先后决定。

学校的云计算实验平台在 clab 点 pku 点 edu 点 cn。本课程实际使用的实验环境是 xLab，下一节手把手带大家连上去。

## P8｜交换分区：内存不够时的救命稻草

云主机的内存往往不大，跑大一点的实验会被系统直接杀掉进程。这时候可以加一块交换分区。

步骤是五步：用 fallocate 建一个四 G 的文件；把它的权限收紧到只有属主可读写；用 mkswap 把它格式化成交换空间；用 swapon 启用；最后用 free 减 h 确认一下。想让它开机自动挂载，就往 etc 下的 fstab 文件里追加一行。

必须说清楚它的代价：交换分区在磁盘上，比内存慢好几个数量级。它防的是「崩溃」，不是「变慢」。程序真正需要的是把内存用量降下来，交换分区只是让你有机会看到结果，而不是让程序变快。

## P11｜公钥登录：在本机生成并读取 SSH 密钥

登录节点用的是公钥认证。一对密钥，各有用途。

先在本机终端执行 ssh 减大写 V，确认装了 SSH 客户端。然后执行 ssh keygen 减 t ed25519 生成密钥。提示保存位置时，没有同名文件就直接按回车用默认路径；如果提示是否覆盖，输入 n，保留已有的密钥；提示设置口令时，直接回车两次。

生成的是两个文件。不带后缀的 id ed25519 是私钥，留在自己的电脑上，不要上传，也不要发给别人。带点 pub 后缀的是公钥，要添加到 xLab，节点用它来验证登录的人是你。

最后用 cat 读出公钥文件，把输出的一整行复制下来，下一步要用。

顺便区分两种认证：登录 xLab 网站用的是校园统一认证，登录 Linux 节点用的是 SSH 公钥认证。

## P22｜目录树与路径

Linux 的文件系统是一棵树，树根就是一个斜杠。

home 目录下是各个用户的主目录，波浪号等价于你自己的主目录。etc 放配置文件。usr 放用户程序，你装的命令大多在 usr 下的 bin 或者 usr local 里。var 放可变数据，日志在 var 下的 log 里。tmp 放临时文件，重启会被清掉，所以不要把有用的东西留在那儿。

路径分两种。以斜杠开头的是绝对路径，从树根开始写。其余是相对路径，其中一个点表示当前目录，两个点表示上级目录，波浪号表示主目录。

## P23｜必会命令（上）

必会命令分两页，先看第一页。

pwd 看当前在哪，ls 列目录，cd 切换目录。ls 减 la 会连隐藏文件和权限一起列出来；cd 减一个减号可以跳回上一个目录。

mkdir 建目录，加 减 p 可以一次把多层目录都建出来；cp 复制，复制目录要加 减 r；mv 既是移动也是改名。

rm 删除。rm 减 rf 会连目录带内容一并删掉，而且不可恢复。

cat、head、tail、less 都是看文件。tail 减 f 可以持续跟踪一个正在增长的日志；less 适合看大文件，按 q 退出。

grep 搜内容，find 搜文件名。grep 减 rn 加上要找的字符串和一个点，就是在当前目录下递归搜索并显示行号，这条命令你这学期会用很多次。

---

## P24｜必会命令（下）

第二页是另外五组。

wc 计数，wc 减 l 数行数。chmod 改权限，最常用的是 chmod 加 x，给脚本加上可执行权限。df 和 du 看磁盘用量，du 减 sh 加星号可以看当前目录下每一项各占多大。ps 和 top 看进程，ps aux 配合管道和 grep 可以找到某个正在跑的程序。kill 结束进程，减九 是强制结束，后面跟进程号。

这一页底下有一句警告，请务必记住：rm 减 rf 没有回收站。一个稳妥的习惯是，执行删除之前，先把命令里的 rm 换成 ls 跑一遍，确认列出来的正是你想删的那些文件，再改回去执行。

## P25｜文件权限

看 ls 减 l 的输出，最左边那一串就是权限。

第一个字符是类型：减号是普通文件，d 是目录，l 是符号链接。

后面九个字符分成三组，每组三位，分别是属主、同组用户、其他人的权限。r 是读，w 是写，x 是执行。

这三位也可以用数字表示：读是四，写是二，执行是一，把它们加起来就是这一组的数字。所以 rwx 是七，r x 是五，只读是四。画面上这个例子写成数字就是七五四，对应的命令是 chmod 七五四，后面跟文件名。

---

## P26｜重定向与管道

这一页是本节最实用的一页。

小于号是输入重定向，让程序的标准输入来自一个文件。大于号是输出重定向，把标准输出写进文件，注意它是覆盖。两个大于号是追加，不覆盖原内容。想把错误信息也一起写进去，在后面加上 二 大于号 与 一 的组合。

竖线是管道，把前一个命令的输出直接送给后一个命令当输入。画面上这条流水线：先 cat 出文件，排序，去重并计数，再按数字倒序排，最后取前几行。这就是一个最小的词频统计。

请特别记住带星号的那一条：python3 空格 你的程序 空格 小于号 空格 in 点 txt。它让你把测试数据存进文件，反复喂给程序，而不用每次手敲。这是本课最常用的一条命令。

## P29｜Python 虚拟环境（uv）

不同项目常常依赖同一个包的不同版本，虚拟环境就是把它们隔离开。本课程用 uv 这一个工具，管好 Python 版本、虚拟环境和第三方包。

第一步，uv python install 三点一四，加上减减 default，由 uv 安装 Python。

第二步，uv init 减减 no package，后面跟项目名，新建一个项目。减减 no package 不能省，否则生成的是发布用的包结构，没有 main 点 py。

进入项目目录后，用 uv add 装包，它会把依赖写进 pyproject 点 toml 和 uv 点 lock。用 uv run 运行程序，它自动使用项目里的点 venv，不需要激活虚拟环境。不要的包用 uv remove 卸载。

环境坏了或者换了电脑，把点 venv 删掉，再执行 uv sync，几秒钟就恢复原样。macOS 和 Linux 上用 rm 减 rf，Windows 的 PowerShell 里用 Remove Item，画面上两种写法都给了。

详细的安装步骤，请看仓库里的 Python 开发环境配置指南。

## P30｜PyCharm 的两个必用功能

PyCharm 有两个功能，请这周就用起来。

## P32｜变量与基本类型

八个类型，一页说完。

int 是整数，Python 的整数没有位数上限，这一点和 C 加加 很不一样，后面算大数的题会占便宜。

float 是浮点数，双精度，大约十五到十六位有效数字。

str 是字符串，不可变。

bool 是布尔值，注意 True 和 False 首字母大写。

list 是列表，可变；tuple 是元组，不可变；set 是集合，无序且自动去重；dict 是字典，存键值对。

后面四个容器是这门课的主力，第四周我们会专门讲它们各自操作的代价。

## P33｜分支与循环

分支用 if、elif、else，条件从上往下依次判断，命中一个就不再往下走。

循环里最常用的是 range。注意 range 的三个参数是起点、终点和步长，而且终点是取不到的。画面上从一开始、到十之前、每次加二，得到的是一三五七九。

如果既要下标又要值，用 enumerate 包住序列，一次拿到两样东西，比自己维护一个计数器清楚得多。

这一页底下有一句警告：Python 用缩进表示代码块，不要混用 Tab 和空格。这是初学者的第二大坑，症状是代码看起来完全正常，却报缩进错误。解决办法是在编辑器里把 Tab 设置成自动转成四个空格。

## P34｜字符串常用操作

字符串这一页，六个方法。

strip 去掉首尾空白，读输入必备。

split 按分隔符切开，返回一个列表；join 是它的反操作，用一个字符串把列表连起来。

方括号里写两个冒号加负一，是把字符串反转过来。

find 查子串的位置，找不到返回负一。

最后一句是原则：字符串是不可变的，想改其中某一位，就先转成列表，改完再 join 回去。

## P35｜列表与二维列表

列表这一页，前半段是常规操作：append 追加，sort 排序，方括号取下标，负一取最后一个，冒号做切片；sum、max、len 分别是求和、最大值和长度。再往下是列表推导式，一行完成「筛选加变换」。

后半段是重点，二维列表的建法。正确写法是用列表推导式，每一行独立地生成一个新列表。错误写法是把一行乘以 m 次，那样得到的 m 行是同一个列表的 m 个别名，改第一行的第一个元素，三行会一起变。

这是初学者的第三大坑，而且它不报错，只是答案不对。请把正确的那一行写法背下来。

## P36｜两道语法练习

两道上周布置过的题，这里当语法练习再做一遍。

第一道，大小写字母互换，题号 E 零二六八九。一行就能解决：读进来直接调用 swapcase。但请把下面的手写版也看一遍：遍历每个字符，小写就把它的编码减三十二，大写就加三十二，其他字符原样保留。这里用到 ord 和 chr 两个函数，它们背后就是 ASCII 编码，第三周会正面讲。

第二道，整数的个数，题号 E 零二六七六。读入一个列表，分别数出一、五、十的个数。

底下这句提醒值得记住：list 的 count 方法每调用一次就扫一遍列表，是线性代价。要统计的值只有三种时这样写没问题；如果要统计的值有很多种，就该用字典一次扫完，而不是对每个值各扫一遍。这种「一次扫完还是扫很多遍」的判断，是第四周复杂度分析的预演。

## P40｜做题前：先把输入模板写熟

## P41｜给零基础同学的做题建议

最后是几条做题建议。

第一，别等「学完」再做题。学到函数就开始做，大部分语法是做题时现查学会的。

第二，看懂评测结果。答案错误，检查边界和输出格式；运行错误，多半是下标越界或者类型没转换；超时，在这三十道题里基本不会碰到，碰到了说明循环写错了。

第三，卡住二十到三十分钟再看题解。看懂以后，关掉题解自己重写一遍，直到通过。只看不写等于没做。

第四，把 AI 当老师，不当代笔。可以让它解释报错、讲语法点、帮你找 bug，但别让它直接写完整代码。机考的时候没有 AI。

第五，先写能跑的代码，暴力、啰嗦都没关系，通过以后再学更简洁的写法。每道题记一行笔记，三十道下来就是你自己的语法速查表。

节奏上，每天三到五题，一到两周做完，比一天做二十题然后停一周效果好得多。
