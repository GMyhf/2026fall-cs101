## P5｜大语言模型在做什么

一句话：给定前面的文字，预测下一个词，准确说是下一个 token。

给它一段输入，比如「计算概论这门课主要用」，模型输出的是下一个 token 的概率分布：Python 零点六二，C 加加 零点一八，Java 零点零五，等等。

然后从这个分布里采样一个，拼回输入，再预测下一个。反复执行这一步，就生成了一整段话。

底下这句话是整节的基础：没有「理解」，只有在海量文本上学到的统计规律。这决定了它擅长接话，不擅长算数，也不擅长记精确事实。

## P6｜（1）分词 Tokenization

第一个部件，分词。文字先被切成 token，也就是子词单元，一句话被拆成 token 序列后，模型才能逐个处理。

## P7｜（2）词向量 Embedding

第二个部件，词向量。每个 token 被映射成一个高维向量，语义相近，向量方向就相近。

用一个玩具例子坐实这一点。三个三维向量：king、queen、apple。前两维大致代表「王室或人」，第三维大致代表「食物」。

用余弦相似度衡量方向，也就是两个向量夹角的余弦，范围是负一到一。king 和 queen 是零点九九六，方向几乎重合；king 和 apple 是零点二六，接近正交。

真实模型里的向量是几千维、由训练学出来的，但「语义等于几何关系」这件事，就是这一页演示的样子。

## P8｜（3）注意力 Attention：概念

第三个部件，注意力。生成每个新 token 时，模型要决定前文里哪些词更重要。注意力就是给前文的每个位置算一个权重，再做加权求和。

分四步理解。Query 是当前要生成的位置，表示「我在找什么」；Key 是前文每个位置，表示「我是什么」；两者做点积，再经过 softmax，得到一组和为一的权重；最后用权重对 Value 加权求和，权重大的位置贡献更多。

二零一七年那篇「Attention is All You Need」提出的 Transformer 架构，正是今天所有大模型的基础。第十五周会把神经网络的其余部分补齐。

## P9｜（3）注意力 Attention：最小实现

注意力的最小实现只有十几行。

softmax 函数里先减去最大值再取指数，这是防止指数溢出的标准技巧，结果不变。

attention 函数三步：用 query 和每个 key 做点积，得到相关度；softmax 归一化成权重；再用权重对 values 加权求和。

看输出：query 是一零。第一个 key 也是一零，和它最像，权重零点四七四最高；第三个 key 零点七、零点七次之；第二个 key 零一和 query 正交，权重最小，只有零点一七四。加权后的输出是十八点七七。

## P11｜幻觉：为什么它会编

一句话：训练目标是「合理」，不是「正确」。模型没有事实数据库，它输出的是在训练数据的统计规律下，这里最可能出现什么。

哪些东西最容易被编？这张表给出四类。

精确标识符，比如 OJ 题号、论文编号、API 版本号：格式规律强、具体值随机，模型只能编一个像的。

时效信息，比如最新版本、今年的规定：训练数据有截止时间。

小众细节，比如冷门函数的参数顺序：训练数据里样本太少。

算术与计数，比如大数乘法、数字符个数：它是逐 token 生成的，不做真正的计算。

本课的实测经验：让 AI 报 OpenJudge 题号，错误率很高。讲义里的每一个题号都必须自己打开链接确认。

## P12｜自检方法

三条自检方法，都很好执行。

第一，换个问法再问一遍。答案不稳定的地方，多半是编的。这一条特别有效，因为编造是随机的，事实是稳定的。

第二，要求给出处。给不出可核验的出处，就当作没有。

第三，凡是数字、编号、链接，一律自己验证。

## P13｜提示词：有效的结构

好的提示词有五个要素：角色、背景、已有尝试、观察到的现象、明确的问题。这一页给了一个模板。

角色：你是一位帮助大一学生的编程助教。背景：我在做 OpenJudge 上的一道题，n 不超过十万，时限一秒。我的尝试：贴上代码。现象：样例过了，提交后超时。问题：我的复杂度是多少？瓶颈在哪一行？

请特别注意最后那一句：请只指出问题，不要直接给完整代码。

这一句是这一页的灵魂。它让 AI 指路而不是代跑，把它从「替你做题」变成「陪你调试」，后者才是你能学到东西的用法。

## P14｜AI 辅助编程：能与不能

左边是推荐的用法。解释报错，把 traceback 贴给它，让它翻译成人话。审查代码，问它「这段代码在什么输入下会出错」，这是 AI 最有价值的用法。补测试数据，让它构造边界情况，然后你自己验证。解释算法，让它用比喻和小例子讲一个你不懂的概念。写样板代码，比如读入模板、格式化输出这类没有思维含量的部分。

右边是红线：不能让它写作业代码然后原样提交；不能相信它给的题号、链接、成绩规则和考试安排；考试中不能使用任何 AI 工具，包括本地模型和 IDE 的智能补全插件。

左边这些的共同点是，你有能力验证结果；右边这些的共同点是，你没有。

## P18｜T1 E29945 神秘数字的宇宙旅行

第一题，模拟。从正整数 n 开始，n 不超过两百万：偶数变成 n 除以二，奇数变成三 n 加一，每一步都输出这次跳跃的算式，直到跳到一，最后输出 End。

代码就是一个 while 循环，按奇偶两个分支输出并更新 n。要注意两点：偶数要用整除，否则会变成浮点数，输出格式就错了；输出的算式格式要和题面一字不差。

为什么一定会停在一？这是著名的「三 n 加一猜想」，目前没人证明对所有正整数成立，但两百万以内已经逐一验证过，题目保证不会死循环。

## P19｜T2 E29946 删数问题

第二题，单调栈加贪心。给一个最多二百五十位的正整数，删掉恰好 k 位，剩下的数字保持原顺序，让结果最小。

思路是：越靠前的数字影响越大。从左到右扫描，只要还有删除名额、当前数字又比栈顶小，就把栈顶弹掉，相当于优先删掉「前面比后面大」的高位数字。

扫完如果名额还没用完，就从末尾删掉剩下的。最后去掉前导零，如果全删光了就输出零。

样例：一七五四三八删四位，答案是一三。这里最容易漏的就是末尾补删和前导零这两处边界。

## P20｜T3 E30091 缺德的图书馆管理员

第三题，模拟，但关键是一个等价转换。走廊坐标从一到 L，学生以速度一行走，两人相向相遇就同时转身。不知道每人一开始朝哪边，求全部离开的最短和最长可能时间。

如果真的去模拟碰撞，既麻烦又容易错。诀窍是：相遇后同时转身，等价于两人互不影响地穿过对方，只是交换了身份。所以每个人的离开时刻，只取决于他到最近或最远出口的距离。

于是最短时间取每人到最近出口距离的最大值，最长时间取到最远出口距离的最大值。样例 L 等于四、位置一和三，输出二和四。还要注意没有学生时输出零。

## P21｜T4 M27371 Playfair密码

第四题，字符串和五乘五矩阵模拟，规则多，考的是细心。

先构造矩阵：密钥去重，后面接上去掉 j 的字母表，j 一律当 i。用一个字典记下每个字母的行和列。

明文按两个字母一组切分：同一组两个字母相同时，中间插入 x，如果这个字母本身是 x 就插入 q；长度为奇数时末尾补一个字符。

加密三条规则：同行，各自右移一格；同列，各自下移一格；否则取矩形对角，也就是本行取对方所在的列。enc pair 的三个分支各对应一种。

样例密钥 keyword，明文 balloon，输出 cbizsces。这道题的坑全在分组规则上，建议逐条对照题面写。

## P22｜T5 T30201 旅行售货商问题

第五题，状态压缩动态规划。三到十八个城市两两连通，从某个城市出发，每城恰好访问一次再回到起点，求最小总费用。

关键是把集合当下标：mask 的第 i 位是一，表示城市 i 已经访问过。dp mask u 表示已访问集合为 mask、当前停在 u 的最小费用。

从城市零出发，初值 dp 一零等于零，其余是无穷大。转移时枚举还没访问的城市 v，把 v 加进集合，更新费用。最后在全集上加上回到起点的费用取最小。

复杂度是二的 n 次方乘 n 平方，n 等于十八时大约八千万次，可以通过。样例输出七。

## P23｜T6 T30204 小P的LLM推理加速

第六题，五星，二分答案加前缀贪心。

第 i 个核的能耗按 x i、y i 交替：第一个周期花 x，第二个花 y，如此往复。总预算是 m，任务可以任意分配，求最多完成多少个周期。

思路是二分周期数 k，再判断 k 是否可行。固定 k 后，让 odd 个核各完成奇数个周期，它们各自多付一个 x，自然选 x 最小的 odd 个，用前缀和求出；剩下的周期两个一组，全部用 x 加 y 最小的那个核来完成。枚举 odd，取最小总成本，不超过预算就说明 k 可行。

二分写成 lo 加一小于 hi 的形式，可行就移 lo，否则移 hi。样例输出四。

## P30｜思考题（2/2）

思考题第二页。
