## P4｜这门课教什么

先看这门课的基本盘。学时是四十八学时理论课，每周三学时；加三十二学时上机实习课，每周两学时。

主线只有一条，编程问题求解。围绕这条主线要练两种思维。数学思维，是把一个现实问题抽象成可以计算的模型；计算机思维，是在有限的时间和内存下，设计出一串真能执行的步骤。这两种思维在后面十五周里会反复出现。

语言以 Python 为主，练习也允许用 C 加加 来完成。

---

## P5｜完成课程后你应当能够

学完这门课，你应当能做到四件事。

第一，用 Python 完成输入输出、控制结构、函数和常用数据结构的操作，并且能读懂基础的 C 加加 程序。

第二，会用复杂度分析、矩阵、排序、贪心、递归、回溯、动态规划和图搜索这些方法去分析并解决问题。

第三，理解图灵机、进程的虚拟地址空间、ASCII 编码这些计算机基本原理。

第四，也是最容易被忽略的一条：在 OpenJudge 这样的评测平台上独立调试程序、自己构造测试数据、并且改进解法。注意这一条说的是独立，不是有人告诉你答案。

## P6｜十六周的节奏

十六周分成四个阶段。

第一到第四周打基础：环境、Shell、计算机原理的上半部分、Python 语法与算法分析。

第五到第九周上强度：十月月考，然后是矩阵、排序、贪心、栈与队列、递归、回溯、并查集。

第十到第十二周攻核心：区间问题、动态规划、广度优先搜索。这三周是全课最硬的一段。

第十三到第十六周融会贯通：计算机原理的下半部分、AI 素养、知识图谱与神经网络，最后是总复习和上机考试。

一句话版本：九月打基础，十月上强度，十一月攻核心，十二月融会贯通。

## P17｜四个概念层层包含

先分清四个经常被混着说的词。

人工智能，是让机器完成通常需要人类智能才能完成的任务，这是最大的那个圈。

机器学习，是从数据里学出规律，而不是把规则写死在代码里。

深度学习，是用多层神经网络来做机器学习，我们在第十五周展开。

大语言模型，是在海量文本上训练的、以预测下一个词为目标的深度模型。

四者的关系是层层包含：人工智能包含机器学习，机器学习包含深度学习，深度学习包含大语言模型。画面上这张图就是这个包含关系。

## P18｜大模型：擅长什么，不可靠在哪

大模型有它明确擅长的地方，也有明确不可靠的地方，用之前要先分清。

它擅长解释概念、翻译报错信息、给出代码骨架、指出常见的坑、帮你构造测试数据。这些场景的共同点是：你有能力验证它说得对不对。

它不可靠的地方是：具体的题号和链接、精确的数值结论、课程事务与考试安排，以及它没见过的新题的正确解法。这些场景的共同点是：你如果不去核实，就完全看不出它错了。

---

## P19｜LLM 的训练目标

为什么会这样？根子在训练目标上。

大语言模型的训练目标是「下一个词最合理」，不是「这句话是不是真的」。它输出的是最像正确答案的那段文字，不是正确答案本身。

理解了这一句，你就能预判它会在什么地方出错：越是需要精确记忆的东西，比如题号、数字、规则条文，它越容易编。

---

## P20｜AI 的三个可以、三个不可以

落到具体做法上，三个可以，三个不可以。

可以让它解释你不懂的报错、语法和算法思想；可以让它审查你已经写完的代码，问一句「这段代码在什么输入下会出错」；可以让它构造边界数据，然后你自己去验证。

不可以直接让它写作业代码然后提交，因为你没学到，而机考的时候没有 AI；不可以相信它给的题号、成绩规则和考试安排；不可以在考试中使用任何 AI 工具，包括本地模型和 IDE 里的智能补全插件。

## P24｜输入的三种基本形态

OJ 的输入永远来自标准输入，最常见的形态有三种，这一页把三种都给全了。

第一种，一行一个整数：用 int 包住 input，读进来直接转成整数。

第二种，一行多个整数，空格分隔：用 input 点 split 切开，再用 map 把每一段转成整数，然后同时赋给两个变量。

第三种，一行是一个整数列表：同样先 split 再 map，最后用 list 收成一个列表。

这三行几乎覆盖了这学期一半以上题目的读入。请注意一个关键事实：input 读回来的永远是字符串，末尾不含换行符。

## P25｜初学者第一大坑：忘了 int

刚才那个事实，反过来就是初学者的第一大坑。

看这段代码：a 读进来是三，b 读进来是四，打印 a 加 b，输出的不是七，是三四。因为它们是字符串，加号做的是拼接，不是加法。

改法很简单，把两个都用 int 转一下，输出才是七。

养成两个习惯：读输入一律记得转换类型；读进来的字符串顺手 strip 一下，去掉首尾的空白。这两个习惯能省掉你这学期很多次莫名其妙的错误。

## P26｜输出的格式控制

输出这边要掌握四件事。

print 传多个参数时，默认用空格分隔；想换成别的分隔符，用 sep 参数。

print 默认在末尾换行；不想换行，把 end 参数设成空字符串。

保留小数位用 f 字符串，冒号后面写点二 f，就是保留两位小数。

最后一个最有用：print 星号加列表，把列表解包成多个参数打印出来，中间自动用空格分隔。这是 OJ 上输出一个数组的标准写法，比自己写循环拼接省事得多。

## P27｜E 零二七五零：鸡兔同笼

第一道例题，题号 E 零二七五零，鸡兔同笼。

题意是：笼子里有鸡和兔，鸡两只脚，兔四只脚，已知脚的总数，问笼子里最少和最多可能有多少只动物。

想清楚两头。要动物最少，就尽量用兔，因为一只兔能消化四只脚；要动物最多，就全用鸡，一只鸡只消化两只脚，所以最多是总脚数除以二。

最少那一头要小心：先全放兔子，如果总脚数正好被四整除，答案就是除以四；如果余二，剩下的两只脚只能再加一只鸡，所以要再加一。

还有无解的情况：脚数是奇数，或者脚数是零，输出两个零。这一类边界判断在这门课里会反复出现，现在就要养成先想边界的习惯。

## P28｜E 零二七三三：判断闰年

第二道例题，题号 E 零二七三三，判断闰年。

大家都背过闰年规则：能被四整除并且不能被一百整除，或者能被四百整除。按这个规则写出来的代码，多半会被判错。

因为这道题的题面里还有一个附加条件：不能被三千二百整除。画面上这行判断，后半段写的是能被四百整除并且不能被三千二百整除。

这道题绝大多数的 Wrong Answer，都来自漏看了三千二百这个条件。它不是知识问题，是读题问题。
