## P4｜Part 1　回溯法

第一部分，回溯法：在解空间树上深度优先地搜索，走不通就退回上一步。

---

## P5｜什么是回溯：DFS 加撤销

先看左边这棵树，它叫解空间树。根是空的选择，每往下一层就多做一个选择，比如先选一，再选二，叶子就是一个完整的方案。

回溯做的事情是：在这棵树上深度优先地走，走到底或者不合法，就退回上一步，撤销刚才的选择，再换一个选择继续走。所以一句话定义：回溯等于深度优先搜索，加上撤销。

右边是通用模板，请背下来。先判断结束条件，满足就把当前路径拷贝一份收进结果，然后返回。否则遍历所有选择：不合法的跳过，这就是剪枝；合法的就做出选择、修改状态，递归下去，回来之后撤销选择、恢复状态。

---

## P6｜三个要素与两个必犯错误

模板里有三个要素。路径，是已经做出的选择；选择列表，是当前还能做什么；结束条件，是什么时候该收下一个答案。后面所有的题，都是往这三个空里填不同的东西。

然后是两个必犯错误。

错误一，忘拷贝。往结果里放的是 path 本身，而不是 path 的拷贝。之后 path 还会被继续修改，最后结果里全是同一个可变对象的最终状态，往往是一串空列表。

错误二，忘还原。选完一个分支忘了撤销，比如忘了 pop，忘了把 used 恢复成假，那么状态就带着上一次的痕迹进入下一个分支，答案会莫名其妙地错。

## P7｜形态一：子集

第一种形态，求所有子集，力扣七十八题。每个元素选或不选，一共二的 n 次方个。

和排列不同的是，这里每一个节点都是一个答案，不只是叶子。所以 dfs 一进来就先把当前路径的拷贝收进结果，因为「选到这里就停」本身就是一个合法子集。

循环从 start 开始，递归时传 i 加一，意思是不能回头选前面的元素。这样每个子集只会按下标递增的顺序生成一次，天然不重复。

一、二、三这三个元素，输出正好八个子集，从空集到全集。

---

## P8｜形态二：组合总和

第二种形态，力扣三十九题，组合总和：从候选数里选出若干个，和等于目标，同一个数可以重复使用。

和上一页比，递归时传的是 i，而不是 i 加一。传 i 就意味着下一层还能再选它自己。rest 表示剩余的额度，减到零就收一个答案。

这一页真正的重点在剪枝那一行。候选数先排好序，那么一旦当前这个数已经比剩余额度大，后面的只会更大，全都不可行，所以用 break 直接结束这一层循环，而不是 continue 继续试下一个。

二、三、六、七凑七，结果是二二三和七两组。break 和 continue 这一个词的差别，常常就是 AC 和超时的差别。

---

## P9｜形态三：带重复元素的排列去重

第三种形态最容易写错：数组里有重复元素，要求排列不重复。

做法两步。先排序，让相同的元素相邻。然后在循环里加一个去重条件：如果当前元素和前一个相同，而且前一个在本层还没被用过，就跳过。

为什么是「前一个没被用过」？如果前一个没被用，说明它和当前的 i 是同一层的兄弟，刚刚在这一层试过相同的值，再试就会产生重复分支。如果前一个已经被用了，说明我们在更深的一层，这时用当前这个是合法的。

记法写在右下角：同一层里，相同的数只允许第一个被选。一、一、二的排列去重后只剩三个。这是本周最难记的一行。

## P10｜对照表：递归参数怎么变

把三种形态并排放一下，差别小得惊人。

子集，递归传 i 加一，力扣七十八。组合、不可重复用，也传 i 加一，力扣七十七。组合、可重复用，传 i，力扣三十九。排列，每层都从零开始遍历，另外用一个 used 数组标记，比如 OpenJudge 零二七四八。

怎么记：只往后走、不回头，就传 i 加一或者 i，前者每个只选一次，后者可以重复选；如果是「哪个都能选，但选过的不能再选」，就用 used 数组。

同一个模板，改一两个参数就换了一类问题。

## P11｜剪枝：让指数变得可行

回溯的复杂度本质上是指数级的，能不能在时限内跑完，取决于剪枝。

三类剪枝。

可行性剪枝：当前选择已经违反了约束，立即 continue 或者 return。八皇后里同列、同对角线就跳过，用的就是这一类。

最优性剪枝：当前的部分解已经比已知最优解差了，直接放弃。求最优解的问题里最常用。

顺序剪枝：排好序之后，一旦当前不可行，后面的都不可行，直接 break。组合总和里候选数大于剩余额度就 break，就是这一类。

## P12｜八皇后（1）：三个集合

例题，OpenJudge 零二七五四，八皇后。八乘八的棋盘放八个皇后，任意两个不能同行、同列、同对角线，按字典序输出第 b 个解。

第一个设计决定是逐行放置。这样「不同行」自动满足，只需要检查列和两条对角线。

用三个集合分别记录已占用的列、已占用的主对角线、已占用的副对角线。检查时三次常数时间的判存在，有冲突就跳过，这是可行性剪枝。

放下去之后，三个集合各加一个，路径加一个；递归回来，三个集合各删一个，路径弹出。前后对称，一个都不能漏。

## P13｜八皇后（2）：为什么用 row 减 c 和 row 加 c

上一页那两条对角线的表示方式，值得单独一页。

看这张三乘三的小表，格子里填的是 row 减 c。同一条从左上到右下的对角线上，row 减 c 是常数；同理，同一条从右上到左下的对角线上，row 加 c 是常数。所以把这两个数丢进集合，就完成了对角线的冲突检测。

运行结果：八皇后一共九十二个解，第一个解是一五八六三七二四，最后一个是八四一三六二七五。

力扣五十一题 N 皇后是同一道题的棋盘输出版，可以作为练习。

## P14｜马走日

例题，OpenJudge 零四一二三，马走日。n 乘 m 的棋盘，马从给定位置出发，问有多少种走法能不重复地走遍所有格子。

八个方向写成一个常量元组，就是之前讲过的方向数组。visited 二维数组记录走过的格子，step 记录已经走了几格，等于格子总数就计数加一。

主体还是模板：检查边界和是否访问过，合法就标记、递归，回来之后取消标记。

请看右边那句话：取消标记这一行就是「回溯」。忘了它，走过的格子永远是走过的，答案要么是零要么是一。

结果是五乘四的棋盘从角上出发有三十二种走法，三乘三的棋盘一种都没有，因为中心那格马根本到不了。

## P15｜DFS 求连通块：Lake Counting

例题，OpenJudge 零二三八六，Lake Counting。网格里 W 表示水，八连通的水域算一个湖，求湖的个数。

做法叫 Flood Fill，漫水填充：扫描网格，遇到一个没处理过的水格，就从它出发把整个连通的水域都标记掉，湖数加一。

这一页的重点是它写成了迭代，用显式栈，而不是递归。理由在右边：一百乘一百的网格，递归深度可达一万，在评测机上有爆栈风险。所以 Flood Fill 一律用显式栈或队列；换成队列，就是第十二周的广度优先搜索，数出来的连通块个数完全一样。

还有一个细节：标记之后再入栈，不要等出栈才标记，否则同一个格子会被重复压进去很多次。

第二部分，并查集，英文缩写 DSU：动态维护「谁和谁在同一组」。

## P17｜它解决什么问题

并查集要解决的是动态维护「谁和谁在同一组」，而且边是一条一条加进来的。

它只支持两个操作。find x：查 x 属于哪个集合，返回这个集合的代表元。union x y：把 x 和 y 所在的两个集合合并。

典型场景：判连通、判环、划分等价类，以及亲戚关系这类问题。

---

## P18｜最朴素的实现

最朴素的实现，用一个 parent 数组表示一片森林。每棵树是一个集合，parent i 等于 i 的时候，i 是树根，也就是这个集合的代表元。一开始每个点自成一组。

find 就是沿着 parent 一路往上走，直到根。union 先找到两边的根，不同就把一个根挂到另一个根下面。

问题在于它会退化成链：连续合并零和一、一和二、二和三，树就变成一条长链，find 变成 O n。

解决办法是两个优化：路径压缩，加按秩或者按大小合并，下一页讲。

---

## P19｜路径压缩加按大小合并

这一页是标准实现，请照抄。

两个优化。路径压缩：find 的路上，把沿途节点直接挂到根上。按大小合并：总是把小树挂到大树下面，树高不会失控。

find 分两趟：第一趟一直往上找到根；第二趟再走一遍，把路上每个节点的父亲直接指向根。请注意它写成了迭代两趟，而不是递归。n 等于十万的时候，递归版可能爆栈，这是本课反复出现的取舍。

union 先各自找根，根相同说明本来就在一组，返回 False；否则把小的挂到大的下面，更新大小，集合个数 count 减一，返回 True。

右下角的测试：合并零一、一二、三四之后，零和二连通，零和三不连通，还剩三组。

## P20｜宗教信仰：数连通块个数

例题，OpenJudge 零二五二四，宗教信仰。n 个学生，给出若干对「信仰相同」的关系，问最多可能有多少种不同的宗教。

本质就是数连通块个数。有了上一页的类，代码只要五行：建一个并查集，把每一对关系 union 一遍，返回 count。

为什么十个学生、三对关系的答案是七？一开始十个人各自成组，零一、一二、三四三次合并各让集合数少一，最后是十减三等于七组。

## P21｜判环：union 返回 False 就是环

第二个直接应用，判环。

无向图里逐条加边，如果 union a b 的时候发现 a 和 b 本来就已经连通，union 返回 False，说明这条边构成了环。

例子里，三个点、两条边零一和一二，没有环；再加一条二零，就形成了环，输出 True。

请把这条记住：union 的返回值就是判环。以后在最小生成树里还会再见到它。

## P22｜食物链：扩展域写法

这是本周最难的一道，OpenJudge 零一一八二，食物链。

题意：三类动物，A 吃 B，B 吃 C，C 吃 A。给出若干句话，要么说「x 和 y 同类」，要么说「x 吃 y」，统计假话有多少句。

技巧叫扩展域：把每个动物拆成三个节点。x 本身是同类域；x 加 n 是猎物域，表示 x 吃的东西；x 加二 n 是天敌域，表示吃 x 的东西。

x 和 y 同类，就把三个域两两对应地 union。x 吃 y，就意味着 y 在 x 的猎物域里，x 在 y 的天敌域里，还有 x 的天敌是 y 的猎物，三组关系同时成立。想清楚这一点，值得反复读三遍。

## P23｜食物链：假话怎么判定

这一页是完整代码。并查集开三 n 个节点。

先判越界：x 或 y 不在一到 n 之间，直接算假话。

如果这句话说 x 和 y 同类：只要 x 已经和 y 的猎物域或者天敌域连通，就矛盾，是假话；否则三个域各自 union。

如果说 x 吃 y：x 等于 y，或者 x 和 y 已经同类，或者 x 和 y 的猎物域连通，也就是 y 反过来吃 x，都是假话；否则做三次 union，分别对应上一页说的三组关系。

不矛盾的话才合并，矛盾的话只计数、不合并，这是判假话类题目的通用写法。

## P24｜食物链：跑一遍样例

## P25｜复杂度：为什么可以当 O 一用

四种实现的对比。

朴素实现，最坏 O n，因为树可能退化成一条链。只做路径压缩，摊还 O log n。只做按秩合并，也是 O log n。两个都做，是 O 阿尔法 n，约等于 O 一。

阿尔法是反阿克曼函数。底下那句话给你一个实感：对任何现实中的 n，阿尔法 n 都不超过四。所以并查集可以当常数时间来用。

## P27｜DFS/BFS 与并查集：什么时候用哪个

这张表给出判据。

数连通块，两者都行。

动态加边之后查询连通性，搜索每次都要重跑，并查集天生支持。

求路径本身，只能用搜索，并查集只知道连不连通。求最短路径，用广度优先搜索，并查集做不到。

判无向图有没有环，两者都行，并查集更简单。

经验法则：只问「连不连通、分几组」，而且边是一条条加进来的，就用并查集；需要路径、距离、遍历顺序的，就用深度优先或广度优先搜索。

## P30｜本周小结

小结五条。

第一，回溯等于深度优先搜索加撤销；模板三要素是路径、选择列表、结束条件；两个必犯错误是忘拷贝、忘还原。

第二，三大形态靠递归参数区分：子集和不可重复的组合传 i 加一，可重复的组合传 i，排列用 used 数组。

第三，剪枝决定回溯能不能跑完：排序之后该用 break 的地方别写成 continue。

第四，经典例题：八皇后用列、row 减 c、row 加 c 三个集合；马走日靠方向数组加回溯还原。

第五，并查集等于路径压缩加按大小合并，摊还近似常数；find 写迭代版防爆栈；union 返回 False 就是判环。
